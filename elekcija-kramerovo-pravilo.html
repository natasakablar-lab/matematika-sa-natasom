Rešavanje sistema Kramerovim pravilom

Reši sistem sa dve ili tri nepoznate pomoću determinanti i prepoznaj kada treba primeniti eliminaciju.

Kramerovo pravilo

  1. Zapiši nepoznate istim redosledom u svakoj jednačini. Kad neka nepoznata izostane, njen koeficijent je 0.
  2. Izračunaj determinantu matrice koeficijenata i označi je sa D.
  3. Za D različito od nule, napravi po jednu novu determinantu za svaku nepoznatu. U svakoj zameni samo kolonu te nepoznate kolonom slobodnih članova sa desne strane. Ostale kolone prepiši iz početne matrice.
  4. Podeli svaku novu determinantu sa D. Dobijaš x = Dx/D, y = Dy/D i, kod sistema sa tri nepoznate, z = Dz/D.

Ako je D = 0, sistem nema jedinstveno rešenje. Eliminacijom proveri da li ima beskonačno mnogo rešenja ili ih nema.

Primer sa D = 0

x + y = 32x + 2y = 8

Koeficijenti drugog reda dvostruko su veći, pa je D = 0. Kad od druge jednačine oduzmeš dvostruku prvu, dobijaš 0 = 2. Sistem nema rešenja.

Samostalna vežba

Konačne odgovore otvori posle pokušaja.

  1. Reši 2x + y = 8x − y = 1.
  2. Reši 3x − 2y = −112x + y = 2.
  3. Reši x + y + z = 6x − y + z = 22x + y − z = 1.
  4. Reši 2x + z = 5x + y − z = 02y + z = −1.
  5. Reši x + 2y − z = 02x − y + 3z = 53x + y + z = 2.
  6. Ispitaj broj rešenja sistema x + y = 42x + 2y = 10.
  7. Ispitaj broj rešenja sistema x − y + z = 32x − 2y + 2z = 6x + y + z = 5.

  5. (−1, 2, 3).

  7. Beskonačno mnogo rešenja. Važi y = 1 i x + z = 4.
