Kvadratne jednačine — rešavanje pomoću diskriminante

Na kraju lekcije moći ćeš da središ kvadratnu jednačinu, odrediš broj njenih realnih rešenja i izračunaš ih kada postoje.

Za početak

Koliko realnih rešenja ima jednačina x² − 5x + 6 = 0? Zapiši svoju pretpostavku i proveri je u prvom primeru.

Postupak u tri koraka

  1. Sredi jednačinu. Prebaci sve članove na levu stranu, saberi slične članove i zapiši ax² + bx + c = 0, pri čemu je a ≠ 0. Očitaj a, b i c sa njihovim predznacima.
  2. Izračunaj diskriminantu. Koristi D = b² − 4ac. Ako je b negativno, pri zameni ga stavi u zagrade.
  3. Odredi broj realnih rešenja i izračunaj ih.
    • D > 0 — dva različita realna rešenja.
    • D = 0 — jedno realno rešenje, dvostruki koren.
    • D < 0 — nema realnih rešenja.

    Kada je D ≥ 0, koristi formulu

    x₁,₂ = (−b ± √D) / (2a).

    Za D = 0 oba znaka daju istu vrednost, x = −b / (2a).

Rešeni primeri

1. Dva različita realna rešenja

x² − 5x + 6 = 0

Koeficijenti su a = 1, b = −5 i c = 6.

D = (−5)² − 4 · 1 · 6 = 25 − 24 = 1. Diskriminanta je pozitivna.

x₁ = (5 − 1)/2 = 2 i x₂ = (5 + 1)/2 = 3.

2. Dvostruki koren

x² − 6x + 9 = 0

Koeficijenti su a = 1, b = −6 i c = 9.

D = (−6)² − 4 · 1 · 9 = 36 − 36 = 0.

Jedino realno rešenje je x = 6/2 = 3.

3. Nema realnih rešenja

x² + 2x + 5 = 0

Koeficijenti su a = 1, b = 2 i c = 5.

D = 2² − 4 · 1 · 5 = 4 − 20 = −16. Pošto je diskriminanta negativna, jednačina nema realnih rešenja.

Šta se vidi na grafiku

Rešenja jednačine ax² + bx + c = 0 su x-koordinate tačaka u kojima grafik funkcije y = ax² + bx + c ima visinu y = 0.

Znak koeficijenta a i oblik grafika

Kada je a = 0, izraz se svodi na y = bx + c. Ako je i b = 0, grafik je horizontalna prava y = c. Formulu za kvadratnu jednačinu koristimo samo kada je a ≠ 0.

Znak diskriminante i broj zajedničkih tačaka sa x-osom

Na graficima iz rešenih primera, obojene tačke označavaju realne korene.

Pravilo o broju realnih korena važi i kada je a < 0. U tom slučaju, za D < 0 cela parabola leži ispod x-ose.

Samostalna vežba

Reši jednačine u skupu realnih brojeva. Za svaku prvo zapiši koeficijente i izračunaj D. Konačne rezultate otvori posle pokušaja.

  1. x² − 7x + 10 = 0
  2. x² + 4x + 4 = 0
  3. 3x² − 2x + 1 = 0
  4. 2x² + 3 = 7x
  5. −x² − 2x + 3 = 0
  6. x(x + 2) = 3x + 2
  7. x² + x − 1 = 0
Prikaži konačna rešenja
  1. x ∈ {2, 5}.
  2. x = −2 (dvostruki koren).
  3. Nema realnih rešenja.
  4. x ∈ {1/2, 3}.
  5. x ∈ {−3, 1}.
  6. x ∈ {−1, 2}.
  7. x ∈ {(−1 − √5)/2, (−1 + √5)/2}.
