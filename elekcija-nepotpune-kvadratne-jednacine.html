Nepotpune kvadratne jednačine

Nauči da prepoznaš koji član nedostaje i izabereš najkraći postupak za nalaženje realnih rešenja.

Koji član nedostaje?

Prvo sredi jednačinu u oblik ax² + bx + c = 0, gde je a ≠ 0. Jednačina je nepotpuna ako je b = 0, c = 0 ili su oba koeficijenta jednaka nuli.

  • Nedostaje linearni član. Iz ax² + c = 0 dobijaš x² = −c/a. Za −c/a > 0 postoje dva rešenja x = ±√(−c/a). Za −c/a < 0 nema realnih rešenja.
  • Nedostaje slobodni član. Iz ax² + bx = 0 izdvajaš x i dobijaš x(ax + b) = 0. Barem jedan činilac mora biti nula, pa su rešenja x = 0 i x = −b/a. Deljenjem jednačine sa x izgubio bi se koren x = 0.
  • Nedostaju oba člana. Iz ax² = 0 sledi x = 0, dvostruki koren.

Rešeni primeri

1. Izdvajanje kvadrata

3x² − 27 = 0

3x² = 27, pa je x² = 9.

Rešenja su x = −3 i x = 3.

2. Kvadrat jednak negativnom broju

2x² + 8 = 0

Sređivanjem dobijaš x² = −4.

Kvadrat realnog broja je nenegativan, pa nema realnih rešenja.

3. Rastavljanje na činioce

5x² + 10x = 0

Izvlačenjem zajedničkog činioca dobijaš 5x(x + 2) = 0.

Sledi x = 0 ili x + 2 = 0, pa su rešenja x = 0 i x = −2.

Kako se rešenja vide na grafiku

Na graficima su obojene tačke na x-osi realni koreni. Prva tri grafika odgovaraju rešenim primerima, a četvrti prikazuje jednačinu 5x² = 0.

Samostalna vežba

Reši jednačine u skupu realnih brojeva. Sedmi zadatak, kao i šesti, prvo sredi tako da na desnoj strani bude nula.

  1. 5x² = 0
  2. 2x² − 18 = 0
  3. 3x² + 12 = 0
  4. 4x² − 12x = 0
  5. −2x² − 6x = 0
  6. 3x² + 2 = 14
  7. 2x² + x = 9x
Prikaži konačna rešenja
  1. x = 0 (dvostruki koren).
  2. x ∈ {−3, 3}.
  3. Nema realnih rešenja.
  4. x ∈ {0, 3}.
  5. x ∈ {−3, 0}.
  6. x ∈ {−2, 2}.
  7. x ∈ {0, 4}.
